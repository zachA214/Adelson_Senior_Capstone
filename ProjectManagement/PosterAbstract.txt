Title: PenTestPocket, a GUI based penetration testing toolkit to be used with all skill levels
Team Name: PenTest Pocket
Team Member: Zachary Adelson
Abstract: The goals for this project were to create a graphical based toolkit for pen testing that was clear and concise in a way where the learning curve was low but could still be used by advanced users without sacrificing flexibility. My method of tackling this project was to get an idea of which tools I wanted to integrate, and integrate them in a generalized way so that subsequent tools could be added with little resistance. I came across lots of time restrictions while attempting to work on my project while balancing other coursework, and to overcome that I had to pivot my goals to shrink the scope of each tool within the toolkit, at least for the scope of the capstone, so that the toolkit has all defined tools but they won't necessarily have every single capability but that all tools are present. Future work would include implementing every aspect of all tools involved and increasing how many tools are present
